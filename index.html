1. Mathematical & Statistical Conventions (Float64 Precision)

All calculations in js/math-engine.js execute in IEEE 754 64-bit floating-point arithmetic adhering strictly to STATISTICAL_STANDARDS.md:

  • Two-Pass Centered Moments: Sample variance s² = (1 / n-1)∑ (x_i - x̄)² uses Bessel’s n-1 correction and two-pass centering.
  • Hyndman–Fan Type 7 Quantiles: Quartiles (Q_1, Q_2, Q_3) and percentiles use linear interpolation at k = (n-1)q + 1.
  • Histogram Density vs Count: Probability density scales bin counts as f̂_k = n_k / (n · w_k) so ∑ f̂_k w_k = 1.0.
  • Kernel Density Estimation: Gaussian and Epanechnikov kernels with Silverman’s bandwidth h = 0.9 min(s, IQR/1.34) n^{-1/5}.
  • OLS & Influence Diagnostics: Closed-form Gauss-Markov OLS, Student-t p-values via Lentz incomplete beta, Blom Normal Q–Q positions p_i = (i - 0.375)/(n + 0.25), leverage h_i, studentized residuals r_i, and Cook’s distance D_i.
2. Local-First Privacy, Security, & Ecosystem Scope
  • 100% Client-Side Processing: Uploaded CSV, TSV, and JSON datasets never leave your browser. Zero external analytics or third-party CDNs are loaded.
  • CSV Injection Protection: Exported CSV cells beginning with =, +, -, or @ are automatically escaped per DATA_CONVENTIONS.md.
  • Shareable URL Safety: Shareable URL hashes encode chart configurations and preset IDs without embedding raw personal datasets.
  • Ecosystem Interoperability: Exchange datasets and outputs with QuartetLab, ResampleLab, and ForecastLab via shared DataSense v1.0.0 JSON schemas.
3. Approved Statistical & Visualization Reference Ecosystem

Grounded in the canonical DataSense standards library (DESIGN.md, STATISTICAL_STANDARDS.md, VISUALIZATION_STANDARDS.md, DATA_CONVENTIONS.md, APPLICATION_GUIDELINES.md, STATISTICAL_AUDIT.md) and reference literature: Claus O.
